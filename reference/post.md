# 커뮤니티, 공지사항 구현

## 커뮤니티, 공지사항 공통 사항
### 페이지 구성
- 목록 페이지
- 상세 페이지
- 생성 페이지
- 수정 페이지

### 공통 컴포넌트
- 하단 페이지네이션 바
- 목록 컴포넌트

## 권한
- 커뮤니티, 공지사항은 누구나 조회 가능
- 공지사항은 admin만 생성, 수정, 삭제 가능
- 커뮤니티 글은 admin, member 모두 생성, 수정, 삭제 가능

## UI/UX 구성

### 목록 컴포넌트 구성 사항
- 1 row에 번호, 제목, 작성자(닉네임), 작성날짜, 조회수 표시

### 상세 페이지
- 본문은 TipTap 기반으로 보여줌
- 본문 아래에 댓글 존재

### 생성, 수정 페이지
- TipTap 기반으로 Wysiwyg 지원
- Simple editor를 사용한다.
- npx @tiptap/cli@latest add simple-editor 를 활용한다.

### 댓글
- 작성자(닉네임), 댓글 본문, 수정, 삭제 버튼
- 수정, 삭제는 본인의 댓글인 경우에만 가능
- 관리자는 모든 댓글을 삭제할 수 있음

### 데이터 구성사항
- 커뮤니티 글은 4가지 카테고리로 구성
  - 자유게시판
  - 베팅게시판
  - 후기게시판
  - 섹시갤러리
- 공지사항은 단일
